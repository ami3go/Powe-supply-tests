# Multilingual Power-Supply Testing Article Index

_Last updated: 2026-09-21_

## Scope

This is a broad, multilingual index of publicly discoverable articles, application notes, technical papers, laboratory guides, academic papers and high-value technical resource hubs devoted to **testing, measuring, validating or characterizing electronic power supplies and power converters**.

It is intentionally broader than the standards inventory. Topics include DC/DC and AC/DC converters, switching supplies, ATX/server supplies, UPS, chargers and OBCs; regulation and efficiency; ripple/noise; load and line transients; control-loop stability/Bode/impedance/PSRR; inrush and protection; switching loss; EMC/pre-compliance; burn-in/HALT/HASS/reliability; production test and automation.

> **Completeness note:** no search can truthfully enumerate every article available on the public Internet. Search engines do not expose a complete corpus, pages change, some sites block indexing, and additional material exists behind logins/paywalls. This file is therefore a **curated, deduplicated living index**, not a claim of literal Internet completeness.
>
> **Language note:** language is based on the actual page/document content where known, not merely the country code in the URL. Localized versions of the same technical article are retained when they are useful to readers in that language.
>
> **Source-quality note:** vendor application notes can contain excellent measurement methodology but are not normative standards. Independent review sites and secondary commercial pages should be used as practical references, not as substitutes for standards, calibrated laboratory procedures or customer requirements.

## Search and maintenance guidance

For future expansion, search in each language for combinations equivalent to:

- power supply testing / power converter testing;
- DC/DC converter measurement / characterization;
- switching power supply ripple measurement;
- load transient / line transient test;
- control-loop stability / Bode plot / output impedance / PSRR;
- power-supply efficiency / harmonic / power-factor measurement;
- overcurrent / short-circuit / protection test;
- burn-in / HALT / HASS / accelerated-life power supply testing;
- conducted/radiated EMI pre-compliance for power converters;
- electronic-load automation / production test;
- UPS/server PSU/ATX testing;
- charger/OBC/V2G power-stage testing.

When adding new links, prefer the original publisher page, record the content language, avoid duplicate mirrors, and tag localized translations separately. If a URL disappears, preserve the title/publisher and replace it with an authoritative archive or the publisher's successor page where legally/publicly available.
